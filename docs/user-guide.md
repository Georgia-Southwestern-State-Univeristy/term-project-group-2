## SpaceHunter – User Guide
### Overview

SpaceHunter is an arcade-style survival game where the player controls a platform to collect energy orbs while avoiding hazards. The game focuses on quick reactions and increasing difficulty over time.

This guide is intended for **players running the game on Windows**, with no technical background required.

### Who This Is For

This guide is for:

- Players installing and playing the game
- First-time users learning controls and gameplay
- Testers evaluating game behavior

### System Requirements
- Operating System: Windows 10 or later
- Processor: Standard modern CPU
- Graphics: Integrated graphics supported
- Installation: No additional software required for exported builds

---

### How to Run the Game

#### Run the Windows Build
- Download the latest release (RC or final version)
  - ```.Exe``` and ```.pck``` files are downloaded in ```.zip``` file
- Extract the ``` .zip ``` file
- Open the folder
- Double-click the ```.exe``` file

#### Starting the Game
- Launch the game
- The main screen appears
- Click the Play button
- Gameplay begins

#### Controls
- Move Left: ← (Left Arrow)
- Move Right: → (Right Arrow)
- Restart Game: Enter

#### Objective
- Catch energy orbs to increase your score
- Avoid or manage asteroids
- Survive as long as possible
- Maintain your attempts

---
### Core Gameplay Workflow
#### Starting a Game

- Launch the game
- Click **Play** on the main screen
- Player gains control of the platform

#### During Gameplay
- Move left and right to align with falling objects
- Catch energy orbs:
  - Score increases
  - Positive feedback is shown
- Avoid or react to asteroids:
  - Causes negative feedback
- Missing objects:
  - Reduces player lives

#### Difficulty Progression
- Object speed increases over time
- Gameplay becomes more challenging
- Requires faster reaction and positioning

#### Game Over
- Player loses all lives
- Game Over screen appears
- Final score is displayed (not saved)
- Press **Enter** to restart

#### Feedback System
The game provides real-time feedback:
- Visual Effects
  - Pulse effects when scoring
  - Camera shake for negative events
- Messages
  - On-screen text feedback

---
#### Known Limitations

The following limitations are known in the Release Candidate:

- No settings menu (controls, or graphics cannot be adjusted)
- No persistent save system or high score tracking
- Game progress resets every session
- Limited UI polish (some alignment or visual inconsistencies may appear)
- Minor performance variation on lower-end systems
- Occasional audio timing inconsistencies in certain situations
- Rare edge-case issues during gameplay or object interactions

#### Tips for Players
- Stay near the center for better reaction coverage
- Avoid risky movements at high speeds
- Focus on survival as difficulty increases
