## Orbital Catcher: Final Release Candidate & Gameplay Systems Demo

Presentation Structure (12–15 minutes)

1. Introduction & Project Overview (1.5 min)
Speaker: Rajesh

- Project concept and objective
- Target player experience
- Brief summary of what the game does

2. Gameplay Walkthrough (2 min)
Speaker: Olga
- Core gameplay loop (catching orbs, avoiding asteroids)
- Player goal and win/lose conditions
- High-level explanation (non-technical)

3. Technical Implementation Highlights (3 min)
Speaker: Olga
- Key systems (spawning, collision handling, scoring)
- Challenges faced and how they were solved
- Brief mention of scripts (e.g., Main.gd, Spawner.gd)

4. Final Polish & Improvements (2 min)
Speaker: Olga
- UI improvements (scoreboard redesign)
- Audio implementation
- Performance and stability fixes

5. Live Demo (3–4 min)
Driver: Olga
Support Commentary: Mario (If Olga require)
- Olga plays the game live
- Mario narrates what’s happening on screen (gameplay-focused)
- Demonstrate:
  - Core loop
  - Scoring system
  - Game over state

6. QA, Testing & Iteration (2 min)
Speaker: Rajesh
- Testing approach (manual playtesting, issue tracking)
- Examples of bugs found and fixed
- Importance of final QA for release readiness
  
7. Reflection & Lessons Learned (1.5–2 min)
Speaker: Mario (primary), Rajesh (add-on if needed)
- What the team learned
- What could be improved with more time
- Takeaways from building the project

---
### Demo Backup Plan

#### If the live demo partially fails:

- Use a pre-recorded gameplay video (hosted locally or in slides)
- Olga explains what would be happening technically
- Mario continues gameplay narration as if live
- Rajesh highlights tested features and expected behavior

#### If build does not run at all:

- Show screenshots + video clips
- Walk through systems using visuals instead of runtime
